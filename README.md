# NLP Customer Complaint Analysis

This project applies Natural Language Processing (NLP) methods to identify patterns and recurring topics in consumer complaint texts.

## Methods

- Text preprocessing and cleaning with NLTK
- Text vectorization with CountVectorizer and TF-IDF
- Topic modeling withLDA and NMF

## Dataset

Consumer Complaint Database from CFPB.  
Due to its size, the dataset must be downloaded separately before running the notebook.

## Results

The analysis extracted common complaint topics related to:

- payments
- credit reporting
- banking accounts
- debt collection
